وزارة التربية الوطنية - منصة نوفل التعليمية

حل التمرين الأول (05 نقاط):
1. تعيين الأعداد \(u_1, u_2, u_3\):
بما أن المتتالية حسابية، فإن \(u_1, u_2, u_3\) حدود متعاقبة، ومنه حسب الوسط الحسابي: \(u_1 + u_3 = 2u_2\).
بالتعويض في المعادلة الأولى \(u_1 + u_2 + u_3 = 15\) نجد:
\[ 2u_2 + u_2 = 15 \implies 3u_2 = 15 \implies u_2 = 5 \]
نعوض \(u_2 = 5\) في المعادلة الثانية \(u_1 \times u_2 \times u_3 = 80\):
\[ u_1 \times 5 \times u_3 = 80 \implies u_1 \times u_3 = 16 \]
لدينا \(u_1 = u_2 - r = 5 - r\) و \(u_3 = u_2 + r = 5 + r\). نعوض في الجداء:
\[ (5 - r)(5 + r) = 16 \implies 25 - r^2 = 16 \implies r^2 = 9 \]
إذن \(r = 3\) أو \(r = -3\). بما أن المتتالية متزايدة تماماً، فإن \(r > 0\)، ومنه \(r = 3\).
ومنه: \(u_1 = 5 - 3 = 2\) و \(u_3 = 5 + 3 = 8\).
2. استنتاج قيمة الأساس والحد الأول:
مما سبق وجدنا مباشرة: الأساس \(r = 3\) والحد الأول \(u_1 = 2\).
3. عبارة الحد العام \(u_n\):
بما أن المتتالية حسابية: \(u_n = u_1 + (n - 1)r\).
\[ u_n = 2 + 3(n - 1) \implies u_n = 3n - 1 \]
4. حساب المجموع \(S_n\) وتعيين \(n\):
المجموع \(S_n = u_1 + u_2 + \dots + u_n\) (مجموع \(n\) حداً):
\[ S_n = \frac{n}{2} (u_1 + u_n) = \frac{n}{2} (2 + 3n - 1) = \frac{n(3n + 1)}{2} \]
تعيين \(n\) بحيث \(S_n = 100\):
\[ \frac{n(3n + 1)}{2} = 100 \implies 3n^2 + n - 200 = 0 \]
نحسب المميز \(\Delta = 1^2 - 4(3)(-200) = 1 + 2400 = 2401\). جذر \(\Delta = 49\).
الحلول: \(n_1 = \frac{-1 - 49}{6} < 0\) (مرفوض لأن \(n\) عدد طبيعي)، أو \(n_2 = \frac{-1 + 49}{6} = \frac{48}{6} = 8\).
إذن: \(n = 8\).
حل التمرين الثاني (07 نقاط):
1. البرهان بالتراجع أن \(0 < u_n < 3\):
- التحقق من صحة الخاصية من أجل \(n = 0\): لدينا \(u_0 = 1\)، وعليه \(0 < 1 < 3\) محققة.
- الفرضية والبرهان: نفرض أن \(0 < u_n < 3\) ونبرهن صحتها من أجل \(n + 1\).
ندرس إشارة الفرق \(u_{n+1} - 3\):
\[ u_{n+1} - 3 = \frac{4u_n + 3}{u_n + 2} - 3 = \frac{4u_n + 3 - 3(u_n + 2)}{u_n + 2} = \frac{u_n - 3}{u_n + 2} \]
حسب الفرضية \(u_n < 3 \implies u_n - 3 < 0\) و \(u_n > 0 \implies u_n + 2 > 0\). إذن الكسر سالب تماماً، أي \(u_{n+1} < 3\).
وبما أن \(u_n > 0\) فإن \(\frac{4u_n + 3}{u_n + 2} > 0\)، أي \(u_{n+1} > 0\). ومنه الخاصية محققة من أجل كل \(n\).
2. دراسة اتجاه التغير والتقارب:
ندرس إشارة الفرق \(u_{n+1} - u_n\):
\[ u_{n+1} - u_n = \frac{4u_n + 3}{u_n + 2} - u_n = \frac{4u_n + 3 - u_n(u_n + 2)}{u_n + 2} = \frac{-u_n^2 + 2u_n + 3}{u_n + 2} \]
جذرا ثلاثي الحدود \(-x^2 + 2x + 3\) هما \(3\) و \(-1\). بما أن \(u_n \in (0, 3)\)، فإن المقدار \(-u_n^2 + 2u_n + 3\) يكون موجباً. والمقام موجب. إذن \(u_{n+1} - u_n > 0\).
المتتالية \((u_n)\) متزايدة تماماً. وبما أنها متزايدة ومحدودة من الأعلى بالعدد **3**، فهي متقاربة.
3. دراسة المتتالية \((v_n)\):
- إثبات أنها هندسية:
\[ v_{n+1} = \frac{u_{n+1} - 3}{u_{n+1} + 1} = \frac{\frac{u_n - 3}{u_n + 2}}{\frac{4u_n + 3}{u_n + 2} + 1} = \frac{\frac{u_n - 3}{u_n + 2}}{\frac{5u_n + 5}{u_n + 2}} = \frac{u_n - 3}{5(u_n + 1)} = \frac{1}{5} v_n \]
إذن \((v_n)\) هندسية أساسها \(q = \frac{1}{5}\)، وحدها الأول \(v_0 = \frac{1 - 3}{1 + 1} = -1\).

- عبارة \(v_n\) و \(u_n\) بدلالة \(n\):
\(v_n = v_0 \times q^n = -1 \times (\frac{1}{5})^n = -(\frac{1}{5})^n\).
لدينا \(v_n = \frac{u_n - 3}{u_n + 1} \implies v_n u_n + v_n = u_n - 3 \implies u_n(1 - v_n) = v_n + 3 \implies u_n = \frac{v_n + 3}{1 - v_n}\).
\[ u_n = \frac{3 - (\frac{1}{5})^n}{1 + (\frac{1}{5})^n} \]
- حساب النهاية:
بما أن \(-1 < \frac{1}{5} < 1\) فإن \(\lim_{n \to +\infty} (\frac{1}{5})^n = 0\).
\[ \lim_{n \to +\infty} u_n = \frac{3 - 0}{1 + 0} = 3 \]
حل التمرين الثالث (08 نقاط):
1. إثبات أن \(L = 3\):
بما أن المتتالية متقاربة نحو \(L\)، ولدينا الدالة المرفقة \(f(x) = \sqrt{x+6}\) مستمرة، فإن \(L\) يحقق: \(L = \sqrt{L + 6}\).
بتربيع الطرفين (مع شرط \(L \ge 0\)): \(L^2 = L + 6 \implies L^2 - L - 6 = 0\).
حلول المعادلة هي \(L = 3\) و \(L = -2\). المرفوض هو \(-2\) لأن \(a_n \ge 0\). إذن \(L = 3\).
2. تبيان العلاقة المطلوبة:
نضرب ونقسم في المرافق:
\[ 3 - a_{n+1} = 3 - \sqrt{a_n + 6} = \frac{(3 - \sqrt{a_n + 6})(3 + \sqrt{a_n + 6})}{3 + \sqrt{a_n + 6}} \] \[ = \frac{9 - (a_n + 6)}{3 + \sqrt{a_n + 6}} = \frac{3 - a_n}{\sqrt{a_n + 6} + 3} \]
3. استنتاج المتباينة:
بما أن \(a_n \ge 0\) (يمكن إثباتها بسهولة بالتراجع)، فإن \(\sqrt{a_n + 6} \ge \sqrt{6} > 0\).
ومنه \(\sqrt{a_n + 6} + 3 > 3\)، وبقلب الطرفين نجد: \(\frac{1}{\sqrt{a_n + 6} + 3} < \frac{1}{3}\).
وبما أن \(3 - a_n \ge 0\) (لأن \(a_n \le 3\))، بضرب الطرفين في \((3 - a_n)\) نجد:
\[ 3 - a_{n+1} \le \frac{1}{3}(3 - a_n) \]
4. البرهان بالتراجع على المتباينة والنهاية:
- من أجل \(n=0\): \(3 - a_0 = 3 - 2 = 1\)، ولدينا \(0 \le 1 \le (\frac{1}{3})^0 = 1\). محققة.
- نفرض أن \(0 \le 3 - a_n \le (\frac{1}{3})^n\) ونبرهن صحتها لـ \(n+1\):
مما سبق لدينا \(3 - a_{n+1} \le \frac{1}{3}(3 - a_n)\). ومن الفرضية نجد:
\[ 3 - a_{n+1} \le \frac{1}{3} \times \left(\frac{1}{3}\right)^n = \left(\frac{1}{3}\right)^{n+1} \]
وطبعاً \(3 - a_{n+1} \ge 0\)، فالخاصية محققة من أجل كل \(n\).

- استنتاج النهاية:
بما أن \(\lim_{n \to +\infty} (\frac{1}{3})^n = 0\)، فإنه حسب مبرهنة الحصر (الدرك):
\[ \lim_{n \to +\infty} (3 - a_n) = 0 \implies \lim_{n \to +\infty} a_n = 3 \]
